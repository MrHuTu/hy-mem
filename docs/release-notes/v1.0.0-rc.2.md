## 本版内容（相对 rc.1）

### 性能：写入链路全面重构，异步 4 条 187s → 22s（-88%）

| 优化 | commit | 效果 |
|---|---|---|

## 已知事项

- serve 空闲 30 分钟自退后，下一个 CLI 调用会付 ~2.8s 冷启动（拉起 serve）；热路径 0.05s。需要极致单条延迟可 `hy-mem serve --idle-exit 0` 常驻
- 语义检索对时间类问题（「昨天做了什么」）天然不命中，用 `list --since` 时间窗（工具描述已注明）
- LLM 密钥走用户级环境变量 `MEMORY_LLM_API_KEY` / `MEMORY_EMBEDDER_API_KEY`，config.json 零密钥；发布前 `check_secrets.py` ERROR=0
