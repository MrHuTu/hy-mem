# R1 · 检索页只做一次

> 父级：`../00-contract.md`　｜　契约条款：C1 / C2 / C6　｜　状态：✓ 已修

## 现象

菜单 → 检索 → 输入查询 → 结果 → `按任意键继续…` → 回主界面。想再查一次必须重新进菜单、
重新敲三项（查询 / 标签 / 条数）。用户原话：「操作完成后按任意键会回到主界面，太繁琐」。

## 根因

`page_search` 是纯线性函数：问 → 查 → 打印 → `return`。返回后由 `run_menu` 统一 `tui.pause()`，
于是每次检索都以「按任意键回主界面」收尾。若想连续检索，成本和重新进功能一样。

## 改法

`page_search` 改为循环：第 2 次起在顶部画分隔线、标题带轮次（`检索（第 N 次）`）。

退出**不再用菜单**：查询内容留空回车即 `return` 回主界面（该分支本来就在）。第 1 轮提示写全
（`留空回车 = 回主界面；查完可直接接着查下一次`），第 2 轮起缩短为 `留空回车 = 回主界面`。
一条查询结束后什么也不问，直接把「查询内容」提示交还——想继续就敲，想走就回车。

初版曾用 `_ask_continue`（`tui.select` 二选一）收尾，2026-10-28 用户澄清后删除：每次检索
多一次按键 + 一次光标移动，而空查询本来就是明确的「不查了」。Esc / Ctrl+C / EOF 同样按
「回主界面」处理（管道把按键喂完时最自然）。

## 红 → 绿

修前（`drive_menu.py /d/tools_open/tmp-m3 "2\n测试查询\n\n3\n\n12\n"`）：

```
检索
› 查询内容: … 返回条数 [5]:
! 无命中
按任意键继续…
选择操作          ← 只查了一次就回主界面
```

修后（同一条按键序列，2026-10-28 实跑）：

```
检索
  留空回车 = 回主界面；查完可直接接着查下一次
  › 查询内容: … 返回条数 [5]:
  ! 无命中
──────────────
检索（第 2 次）
  留空回车 = 回主界面
  › 查询内容:      ← 直接可查，无「再查一次？」菜单
按任意键继续…
选择操作          ← 空回车才回主界面
```
