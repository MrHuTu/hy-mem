## 1. 这一片做什么

请求链路修好后，界面仍显示「嵌入密钥 未设置」。因为三处展示同样只看 `apiKey` 字段，
而该字段按设计恒为空 —— 与事实相反，会把用户带向"key 没配好"的错误结论。

## 2. 怎么改

| 文件 | 改动 |
|---|---|
| `cli/hy_mem_cli.py`（`config show`） | 密钥行显示来源：`已设置（来自 $MEMORY_EMBEDDER_API_KEY）` / `未设置` |
| `cli/menu.py`（设置页概览） | 同上 |
| `cli/setup_wizard.py:_summary_rows`（向导摘要） | 同上，保留打码后的尾号 |

## 3. 验收

| 步 | 命令 | 期望 |
|---|---|---|
| 绿 | `hy-mem config show` | 密钥行不是「未设置」 |
| 绿 | 向导走完的摘要页 | 同上一行 |

## 4. 风险与回滚

- 影响面：纯展示，不影响任何写入与请求。
- 回滚：单独撤回这三处即可。
